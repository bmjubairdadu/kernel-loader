# Security Policy

## Supported Versions

Kernel Loader actively maintains security updates and patches for the latest release branch.

| Version | Supported          |
| ------- | ------------------ |
| 5.8.x   | :white_check_mark: |
| 5.7.x   | :white_check_mark: |
| < 5.7   | :x:                |

## Reporting a Vulnerability

We take the security of Kernel Loader, device root execution, and driver integrity seriously.

If you believe you have found a security vulnerability in Kernel Loader:

1. **Do not create a public issue** disclosing the vulnerability.
2. Please reach out privately to the maintainer via Telegram: [@Jubairdadubm](https://t.me/Jubairdadubm).
3. Provide a detailed summary including:
   - Description of the vulnerability.
   - Attack vector and affected components.
   - Steps or proof-of-concept (PoC) to reproduce.
   - Suggested mitigations if known.

We will review reports promptly and work on an expedited fix or release before public disclosure.
